# Fotoğraflar

Saat fotoğraflarını bu klasöre koy, sonra ilgili saatin kaydındaki `photos`
dizisine yolunu yaz:

```json
"photos": ["photos/omega-speedmaster-1.jpg", "photos/omega-speedmaster-2.jpg"]
```

Listedeki ilk fotoğraf kapak görseli olarak kullanılır.

**İpuçları**

- Dosya adında Türkçe karakter ve boşluk kullanma: `tudor-bb58-kadran.jpg` gibi.
- Kapak görselleri için 4:3 oran iyi durur; 1600 px genişlik fazlasıyla yeter.
- Büyük dosyalar depoyu şişirir — mümkünse 500 KB altında tut (JPEG kalite ~80
  ya da WebP).
