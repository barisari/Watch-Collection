GÖREV: Görev yoklamanı zamanlayıcıdan "izleyici"ye çevir ve bunu kalıcı
yap. Şu an 5/15/30 dakikada bir kendin uyanıp bakıyorsun. Görev olmasa da
her bakış bir model turu, yani kullanıcının token'ı. Yeni yöntemde bakma
işini arka planda küçük bir betik yapıyor, sen yalnızca iş gelince
uyanıyorsun.

İstenen davranış:
1. Arka planda bir betik 30-60 sn'de bir bulut dalının başını okur:
   git ls-remote origin refs/heads/claude/watch-collection-manager-gl4ziq
   Bu komut yerel depoya hiçbir şey yazmaz.
2. Baş değişmediyse betik beklemeye devam eder. Değiştiyse git fetch yapar
   ve iki şeye bakar:
   - Bekleyen görev var mı? Yani bulut dalında bridge/tasks/ altında olup
     bridge-local dalında bridge/results/ altında karşılığı olmayan dosya.
   - bridge/SESSION.md'nin ilk satırı DURUM: KAPALI mı?
   İkisinden biri doğruysa betik çıkar ve seni uyandırır. Hiçbiri doğru
   değilse bulut oturumu başka bir dosya göndermiş demektir (CLAUDE.md,
   veri gibi). O zaman betik yeni başı taban alır ve beklemeye devam eder,
   seni uyandırmaz.
3. Uyanınca bugünkü gibi davran: görevi yap, sonucu gönder, betiği yeniden
   başlat. KAPALI geldiyse betiği yeniden başlatma, bugünkü gibi dur.
4. Betik yalnızca okur (ls-remote, fetch, ls-tree, show). Kurulum ya da yeni
   program gerekmiyor, git zaten var. Döngünün kapsamı da değişmiyor.

Uygulaman arka plan komutlarına süre sınırı koyuyorsa (örneğin 30 dk),
betik süre dolunca da çıksın. Sen uyanıp yeniden başlatırsın. Boştayken
maliyet bugünkü 30 dk turuyla aynı kalır, ama görevler anında alınır.

Uygulaman arka planda çalışan bir komutun bittiğinde seni uyandırmasına
izin vermiyorsa bunu sonuca yaz ve bugünkü 5/15/30 düzeninde kal.

Örnek: bulut tarafında sınanan hâli (bash). Windows'ta PowerShell'e ya da
Git Bash'e sen uyarla. Depo kökünde çalışır.
```bash
bulut=claude/watch-collection-manager-gl4ziq
bekleyen() {  # görev dosyası olup sonucu olmayanlar
  comm -23 <(git ls-tree --name-only "origin/$bulut:bridge/tasks" | sort) \
           <(git ls-tree --name-only origin/bridge-local:bridge/results 2>/dev/null | sort)
}
uyandir() {   # 0 dönerse seni uyandıracak bir şey var
  git show "origin/$bulut:bridge/SESSION.md" | head -1 | grep -q KAPALI && { echo KAPALI; return 0; }
  [ -n "$(bekleyen)" ] && { echo GOREV; return 0; }
  return 1
}
git fetch -q origin "$bulut" bridge-local; uyandir && exit 0
son=$(git rev-parse "origin/$bulut")
while :; do
  sleep 30
  simdi=$(git ls-remote origin "refs/heads/$bulut" | cut -f1)
  [ -z "$simdi" ] || [ "$simdi" = "$son" ] && continue
  git fetch -q origin "$bulut" bridge-local || continue
  uyandir && exit 0
  son=$simdi    # başka bir dosya değişmiş: uyanmadan beklemeye devam
done
```
